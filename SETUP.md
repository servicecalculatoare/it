## 🚀 Cum să Utilizezi

### 1. Clonează Repository-ul
```bash
git clone https://github.com/servicecalculatoare/it.git
cd it
```

### 2. Deschide în Browser
```bash
# Simplu deschide index.html în browser
# Sau folosește un local server
python -m http.server 8000
# Apoi acces la http://localhost:8000
```

### 3. Pentru Development
```bash
# Folosește Live Server sau similar
# VS Code: Instalează extensia "Live Server"
# Click dreapta pe index.html → "Open with Live Server"
```

## 📝 Personalizare

### Schimbă Contact Info
Edit în `index.html`:
```html
<p>+40 (21) 123-4567</p>
<p>contact@itservices.ro</p>
```

### Modifică Serviciile
Edit secțiunea `#services` în `index.html` cu serviciile tale.

### Schimbă Culori
Edit variabilele CSS în `css/style.css`:
```css
:root {
    --primary-color: #0066cc;
    --secondary-color: #00d4ff;
}
```
